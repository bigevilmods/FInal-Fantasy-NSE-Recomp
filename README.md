# Final Fantasy NSE Recomp
Final Fantasy Recomp
Pre Requisites
- Microsft Visual Studio C++ Compiler.

Working: 
- Save State
- Up to 4K Resolution
- 32 bit colors

Controls:
F2 - Open Menu
F5 - Save game state
F9 - Load Save state
Space  : action
Enter = Start 
arrows = control

How to USE ?
Place your "Final Fantasy (USA).nes" ROM in the same Folder and click on Build, it will generate a executable.
